# Soccer Stats Analysis (R Project)

This project analyzes top international football forwards who scored 50+ goals for their national teams.  
The report explores historical scoring dynamics, career length, match frequency, and modern changes in football performance.

## Contents
- Data cleaning and preprocessing
- Feature engineering (career length, years to reach 50 goals)
- Exploratory analysis
- Visualizations (ggplot2)
- Key insights and conclusions

## Files
- `01_soccer_stats.html` — full interactive report
- `02_goalscorers.csv` — dataset. The original name of the dataset is ‘50+ Football’s All-Time International Goal Scorers’. The dataset was created by Kamran Ali and licensed under CC BY-SA 3.0
